# Webサーバー仕様

## 1. 概要

- **対象OS**: Windows 11
- **Ansible Role**: `web_server`

## 2. インストール・設定される機能/ソフトウェア

| 機能/ソフトウェア | 説明                               |
| ----------------- | ---------------------------------- |
| IIS               | WindowsのWebサーバー機能           |
| サクラエディタ    | テキストエディタ                   |

## 3. 設定詳細

`web_server` Roleは、以下の機能・ソフトウェアをインストール・設定します。

- **IIS:**
    - `Web-Server` Windows Featureを有効化する。
    - デフォルトウェブサイトが実行状態であることを確認する (特別なサイト設定は不要)。
- **サクラエディタ:**
    - 公式サイトからインストーラーをダウンロードする。
    - ダウンロードしたインストーラーを実行し、サイレントインストールを行う。

## 4. Ansible Role (`web_server`) のタスク概要

1.  `win_feature` モジュールを使用してIIS (`Web-Server`) をインストールする。
2.  `win_get_url` モジュールを使用してサクラエディタのインストーラーをダウンロードする。
3.  `win_package` モジュールを使用してサクラエディタをインストールする。
