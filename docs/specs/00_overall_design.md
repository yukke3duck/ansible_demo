# 全体設計

## 1. 概要

このプロジェクトは、Ansibleを使用して以下の2種類のサーバーの構築と設定を自動化することを目的とします。

- **Webサーバー**: Webアプリケーションをホストする。
- **プロキシサーバー**: Webサーバーへのリクエストを中継する。

## 2. システム構成図

```
[AWX] --(Ansible)--> [Proxy Server] --(HTTP)--> [Web Server]
```

## 3. 対象サーバー

| サーバー種別     | OS             | ホストグループ   |
| ---------------- | -------------- | ---------------- |
| プロキシサーバー | Ubuntu 22.04   | `proxyservers`   |
| Webサーバー      | Windows 11     | `webservers`     |

## 4. Ansible実行環境

Ansible PlaybookはAWXから実行されることを想定しています。
